# Разработка и Общение

Версия: 1.0.20261001.1 (дата системы: 2026-10-01).

## Использование

- **Общение** — вопросы, обсуждение архитектуры, объяснения. Один запрос к модели, без планирования, инструментов, команд и Git. Скорость зависит от модели и провайдера.
- **Разработка** — явно поставленные задачи с выполнением действий через существующие инструменты проекта и Git.
- Пока выполняется разработка, можно переключиться в Общение и отправить вопрос. Каждый чат допускает один активный запрос. На вкладках показывается фоновая работа.
- Обсуждение не запускает разработку. Для выполнения напишите задачу во вкладке Разработка.
- Медиа и вложения доступны в Разработке через существующий медиарежим. Общение — текстовый режим. На время медиазапроса переключение вкладок заблокировано.

## Общий контекст и сохранение

Оба чата получают название, стек, описание проекта и последние 24 сообщения другого чата (до 24000 символов содержимого). Передаётся снимок на момент запроса; ещё не завершённый ответ попадёт в последующий запрос. История другого чата обозначена как справочные данные, не разрешение выполнять действия.

Полные истории сохраняются в проекте с типом чата. Старые сообщения без типа относятся к Разработке. Кнопка нового запроса очищает поле ввода, но не удаляет переписку.

Черновики и вложения сохраняются раздельно: существующий `draft-<hash>.json` для Разработки и `draft-<hash>.conversation.json` для Общения в каталоге AttachmentService.Root. Хеш определяется рабочей папкой проекта. Проекты с одинаковой рабочей папкой используют одни черновики. Загрузка и переключение не перезаписывают ещё не прочитанный черновик.

Смена проекта и закрытие окна заблокированы во время активных запросов/синхронизации, чтобы агент не продолжал незаметно менять предыдущий проект. Отмена окна выбора проекта не закрывает уже открытый проект.

## Проверки

- `python tools/test_dual_chat.py` — два автономных теста с подменой API: общение без инструментов/плана и разработка с инструментами/общим контекстом.
- `dotnet run --project artifacts/chat-tests/ChatTests.csproj` — пять проверок: последние сообщения, ограничение контекста, неизменность исходной истории, миграция старых сообщений, JSON roundtrip двух чатов.
- `dotnet build AIEngineerStudio.Wpf.csproj --no-restore -o artifacts/dual-chat-20261001` — сборка отдельно от запущенного приложения.

Для ручной приёмки: запустите собранное приложение, напишите разные черновики в обеих вкладках, перезапустите, проверьте восстановление. Запустите разработку и параллельно отправьте вопрос в Общение; убедитесь, что ответы и статусы остаются в своих вкладках. Проверьте общий контекст следующим запросом после завершения ответа.

Реальные API-запросы и интерактивные сценарии интерфейса в этой проверке не выполнялись. Управление мышью не использовалось.
