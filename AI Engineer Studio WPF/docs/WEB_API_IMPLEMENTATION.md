# Web API

Добавлен отдельный ASP.NET Core проект `WebStudioApi/WebStudioApi.csproj`, включённый в `AIEngineerStudio.Wpf.slnx`.

## Реализовано

- HTML5/CSS/JavaScript клиент в `WebStudioApi/wwwroot`.
- ASP.NET Core Identity и роли `Администратор`, `Разработчик`.
- Серверная авторизация для API.
- Изолированная корневая папка проектов и защита относительных путей.
- Создание проектов, список файлов, чтение, запись и удаление.
- Аудит входа/файлов/чата в `data/audit.log`.
- Серверный вызов существующего Python AI bridge; ключ не выдаётся браузеру.
- Исправлено использование автоматически выбранной модели в development-цикле обоих WPF bridge: теперь API-вызов использует `selected_model`, а не исходную ручную модель.

## Ограничения текущего этапа

Загрузка/скачивание файлов, переименование/удаление проектов, белый список Git и процессов, полноценный серверный live-чат с сохранением истории, динамический каталог моделей через провайдер и production hardening требуют дальнейшего этапа. API сейчас является минимальным защищённым каркасом, а не готовой production-публикацией.

`ProjectsRoot`, `PythonPath`, `BridgePath`, `ApiKey` и `BaseUrl` задаются серверной конфигурацией/секрет-хранилищем. Не помещайте ключ в `wwwroot`, git или ответы API.
