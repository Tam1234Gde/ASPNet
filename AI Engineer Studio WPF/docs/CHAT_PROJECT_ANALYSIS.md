# Анализ проекта в чате «Общение»

Чат «Общение» теперь может читать дерево, искать и читать текстовые файлы проекта, а также получать актуальный справочный статус чата «Разработка». Команды, SSH, запуск процессов и изменение исходников недоступны.

По явному запросу модели создаётся запрос на информационный файл (`.md`, `.txt`, `.json`, `.yaml`, `.yml`). Приложение показывает подтверждение перед записью и не перезаписывает существующий файл без согласия.

Секретные и служебные каталоги исключены. Результаты анализа — справочные данные; готовность проекта подтверждается только реально выполненными проверками.

Изоляция сохраняется по пути текущего проекта. При смене проекта поздний запрос отклоняется.
