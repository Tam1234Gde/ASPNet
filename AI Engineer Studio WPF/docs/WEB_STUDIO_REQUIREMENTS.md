# Требования к веб-версии AI Engineer Studio

## Цель
Создать в существующем решении отдельный проект веб-версии AI Engineer Studio на HTML5/CSS/JavaScript с современным интерфейсом и визуальными эффектами. Веб-версия должна предоставлять функции текущего приложения агента ИИ-студии.

## Согласованные решения

- В решение добавляется отдельный веб-проект по типу WebSiteDev.
- Клиентская часть: HTML5, CSS, JavaScript.
- Веб-версия должна уметь управлять проектами и файлами сервера: создавать, читать, изменять, удалять, загружать и скачивать файлы.
- Должны поддерживаться создание, переименование и удаление проектов.
- Разрешён запуск и остановка разрешённых процессов разработки.
- Разрешены операции Git.
- Серверный компонент: ASP.NET Core в составе решения.
- ASP.NET Core API вызывает существующий AI bridge на сервере.
- API-ключи и AI-операции не передаются напрямую в браузер.
- Для защиты используется обязательная авторизация и роли доступа.
- Используется ASP.NET Core Identity.
- Предусмотрены роли:
  - Администратор — полный доступ, включая пользователей и настройки.
  - Разработчик — работа с проектами, файлами и разрешёнными операциями.
- Область доступа к файлам: любые файлы, доступные серверу согласно фактическим правам системной учётной записи приложения Ubuntu.

## Ограничения и безопасность

- Фактический доступ ограничивается правами Linux-пользователя, под которым работает ASP.NET Core.
- Авторизация и проверка ролей обязательны для операций API.
- Запуск процессов и Git-операции должны выполняться через разрешённые серверные операции API.
- Секреты и API-ключи должны оставаться на сервере.
