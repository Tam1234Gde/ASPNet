# Вложения и медиа

- Кнопка «Вложения»: до 8 файлов, по 25 МБ. Также доступны перенос файлов и вставка файлов/картинок из буфера.
- Копии хранятся в `%LOCALAPPDATA%/AIEngineerStudio/Attachments`; исходники не изменяются. Удаление карточки убирает только вложение из черновика. Физическая очистка намеренно не выполняется без разрешения пользователя.
- Черновик сохраняется отдельно для рабочей папки. История сохраняет ссылки на локальные копии; перенос проекта на другой компьютер требует переноса этих файлов.
- При наличии вложений используется прямой мультимодальный диалог без инструментов агента. Для возвращения к агенту начните новый чат.
- Режимы кнопки «Медиа»: диалог, создание изображения, редактирование изображения, видео по тексту/фото, ремикс видео по серверному ID.
- Укажите реальный ID медиа-модели и поддерживаемые ей размер/длительность. Это не модели обычного каталога по умолчанию.

## Протоколы и ограничения

Используются OpenAI-совместимые `chat/completions`, `images/generations`, `images/edits`, `videos`, `videos/{id}/remix`, опрос `videos/{id}`, скачивание `videos/{id}/content`.
Передаются image_url, video_url, input_audio (MP3/WAV), file_data. Поддержка зависит от сервера и модели, особенно video_url и произвольных документов.
Ответы: текст, структурированные изображения и результаты image API, видео из video API. Универсальные входящие документы и аудиофайлы, Markdown-ссылки как вложения пока не реализованы.
Редактирование видео — только серверный ремикс по ID. Монтаж локального видео, маски для изображений и таймлайн не реализованы.
Локальная инструкция API DUCK не подтверждает эти медиа-endpoints. Реальные сетевые запросы не проверялись: необходимы поддерживающий API и медиа-модель.
При отмене останавливается клиентское ожидание. Серверная задача может продолжиться и тарифицироваться.
Отображается статус операции, но не процент загрузки. После ошибки черновик остаётся для повторной отправки.
Максимальный скачиваемый результат: 200 МБ. HTTPS обязателен, ключ не передаётся хосту URL результата. Файлы автоматически не исполняются.
