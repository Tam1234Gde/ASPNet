# CORETECH-IT - HTML Website

Полностью готовый сайт на чистом HTML, CSS и JavaScript.

## 🚀 Как запустить

### Вариант 1: Просто открыть файл

1. Найдите папку `html-site`
2. Двойным кликом откройте файл `index.html`
3. Сайт откроется в браузере!

### Вариант 2: Через VS Code с Live Server

1. Откройте папку `html-site` в VS Code
2. Установите расширение "Live Server"
3. Правой кнопкой на `index.html` → "Open with Live Server"

## 📁 Структура файлов

```
html-site/
├── index.html    - Основной HTML файл (весь сайт)
├── style.css     - Все стили и анимации
├── script.js     - JavaScript для интерактивности
└── README.md     - Эта инструкция
```

## ✨ Возможности

- ✅ **Кастомный курсор** с зелёным неоновым эффектом
