# CORETECH IT DEV - Руководство по использованию

## Установка API ключа

### Способ 1: Через интерфейс приложения (Рекомендуется)

1. Запустите приложение `CORETECH_IT_DEV.exe`
2. Нажмите кнопку **⚙️ Settings** в левой панели
3. В поле **API Key (Your CVC Token)** введите ваш ключ:
   ```
   sk-cvc-8f869cae5afbadb7f7b8f3197733541084bfe93f146a64a1fde9e4cc3a636eed
   ```
4. Нажмите кнопку **Save**
5. Ключ будет сохранен в файл `.env` в корне проекта

### Способ 2: Ручное редактирование файла .env

Отредактируйте файл `.env` в корне проекта:

```env
ANTHROPIC_BASE_URL="https://apiduck.sytes.net"
ANTHROPIC_AUTH_TOKEN="sk-cvc-8f869cae5afbadb7f7b8f3197733541084bfe93f146a64a1fde9e4cc3a636eed"
ANTHROPIC_MODEL="claude-sonnet-4-6"
```

После сохранения перезапустите приложение.

## Основные возможности

### 1. Выбор модели AI
В боковой панели выберите нужную модель из выпадающего списка:
- **claude-sonnet-4-6** - для написания кода и рефакторинга
- **gpt-5.6-terra** - универсальная модель для сложных задач
- **gpt-5.6-luna** - быстрая модель для простых задач
- **deepseek-v4-flash** - сверхбыстрая генерация кода
- **deepseek-v4-pro** - для математических расчетов
- **grok-4.5** - креативные решения
- **claude-opus-4-6** - глубокое рассуждение
- **qwen3.7-max** - работа с JSON и данными
- **kimi-k3** - обработка больших контекстов

### 2. Работа с проектом
- **📁 Choose Project Folder** - выбрать папку проекта
- **➕ Add Files to Project** - добавить файлы в проект

### 3. Чат с AI
Введите запрос в текстовое поле внизу и нажмите **Send 🚀**

AI будет:
- Читать и анализировать файлы проекта
- Создавать и изменять файлы
- Показывать процесс работы в реальном времени
- Автоматически коммитить изменения в Git

### 4. Отображение изменений в реальном времени
Когда AI работает с файлами, вы увидите уведомления прямо в чате:
```
🔧 File modified: MainWindow.xaml
🔧 File created: Services/NewService.cs
```

### 5. Автоматические Git коммиты
Приложение автоматически:
- Инициализирует Git репозиторий в папке проекта
- Создает коммиты при изменении файлов AI
- Коммитит каждые 30 секунд при наличии изменений
- Сохраняет историю всех изменений

### 6. Расширенные настройки

В настройках доступны:

#### API Base URL
```
https://apiduck.sytes.net/v1
```

#### System Prompt (Расширенные настройки)
Вы можете настроить поведение AI, изменив системный промпт. По умолчанию:
```
Ты — автономный ИИ-разработчик. У тебя есть доступ к структуре и файлам проекта через инструменты.
```

Примеры кастомизации:
- Добавьте правила кодирования для вашей команды
- Укажите предпочтительные библиотеки и фреймворки
- Определите стиль комментариев и документации

## Автоскролл в чате

Чат автоматически прокручивается вниз при получении новых сообщений. Если вы прокрутите вверх для чтения истории, автоскролл отключится. Прокрутите в самый низ, чтобы включить его снова.

## Кнопка "Apply File Directives"

Если AI предлагает изменения в виде директив файлов (код-блоки с путями), нажмите эту кнопку, чтобы автоматически применить все изменения к проекту.

## Список файлов проекта

В левой панели отображаются все файлы проекта (исключая `.git`, `bin`, `obj`, `.vs`). Список автоматически обновляется при изменениях.

## Компиляция проекта

Для компиляции используйте:

```bash
dotnet build CORETECH_IT_DEV.sln
```

Или используйте файл:
```bash
build.bat
```

Для запуска:
```bash
run.bat
```

## Устранение проблем

### Ошибка "API Key is not configured"
- Убедитесь, что вы ввели ключ в настройках
- Проверьте файл `.env` в корне проекта
- Перезапустите приложение

### Не отображается текст в выпадающем списке моделей
Исправлено: текст теперь темный на светлом фоне для читаемости.

### Модальное окно настроек обрезается
Исправлено: добавлен ScrollViewer и увеличена высота окна.

### Git не работает
Убедитесь, что Git установлен в системе:
```bash
git --version
```

Если Git не установлен, скачайте с https://git-scm.com/
