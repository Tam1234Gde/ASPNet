# Отчёт: расширение T-Invest API и обучение

## Выполнено

1. Изучены материалы `res`, текущий SDK `t-tech-investments 1.51.0` и его сервисы.
2. Составлена карта доступных направлений: Users, Instruments, MarketData, Operations, Orders, StopOrders, Sandbox, Signals и streaming.
3. Добавлен `app/api_facade.py`: единый фасад чтения с ограниченными повторами и безопасным логированием типа ошибки без токена/тела ответа.
4. В Telegram добавлена ветка `/api` с клавиатурой и разделами: счета, профиль, тариф, маржа, вывод, операции, рынок, свечи, карточка и поиск инструмента, дивиденды, купоны, расписание, избранное, страны, стоп-заявки.
5. Существующие торговые команды сохранены. Новые API-разделы сделаны информационными. Денежные переводы, открытие/закрытие счёта, выставление произвольных рыночных и стоп-заявок не добавлены в чат: это рискованные операции, для них требуется отдельное проектирование подтверждения и идемпотентности.
6. Добавлен `app/learning.py`. Он сохраняет версионированную агрегированную статистику решений в `state/learning.json` атомарной заменой файла.
7. AI-клиент регистрирует каждое валидное решение. `/learning` показывает накопленную статистику. Самоизменение кода и автоматическая смена риск-лимитов запрещены.
8. Добавлены тесты хранения обучения и повторов read-only API.

## Использование

- `/api` — открыть API-меню.
- `/api market UID` — цена, стакан и торговый статус.
- `/api candles UID` — часовые свечи за сутки.
- `/api search Сбербанк` — поиск.
- `/api dividends UID`, `/api coupons UID` — выплаты.
- `/learning` — статистика опыта.

## Покрытие и ограничения

Поддержано максимально безопасное интерактивное чтение основных unary-методов. Потоковые методы требуют постоянно живущих подписок и не выводятся напрямую в чат. Методы Signals, расширенная аналитика/фундаментальные отчёты и генерация брокерских отчётов имеют сложные cursor/request-схемы; SDK доступен через фасад для последующего специализированного UI. Production-торговля проектом по-прежнему заблокирована, торговля возможна только в Sandbox по существующему контуру подтверждений и лимитов.

«Обучение» означает накопление проверяемой статистики, а не обещание доходности. Доходность не гарантируется; критическая логика не переписывается автоматически.
