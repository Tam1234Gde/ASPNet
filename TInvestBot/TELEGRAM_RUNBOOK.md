# Telegram: запуск, перезапуск и проверка

## Запуск

Из каталога проекта запустите `START_TELEGRAM.bat`.
Окно можно оставить открытым или запускать через `RESTART_TELEGRAM.bat`.

## Перезапуск без потери данных

Запустите `RESTART_TELEGRAM.bat`. Скрипт:

1. останавливает только процесс Telegram;
2. ждёт его завершения;
3. запускает новую версию;
4. не удаляет `state`, SQLite-базы, курсоры и историю транзакций.

Для отдельной остановки: `STOP_TELEGRAM.bat`.

## Проверка после перезапуска

1. Откройте `state/telegram.stdout.log` — должна появиться строка `TELEGRAM_CONNECTED`.
2. При ошибке прочитайте `state/telegram.stderr.log`.
3. В Telegram отправьте `/start` — должна появиться клавиатура.
4. Нажмите `📊 Статус`, `📈 Портфель`, `🧰 Инструменты`, `🧾 Транзакции`.
5. Для обновления списка инструментов нажмите `/sync_instruments` или отправьте команду вручную.
6. Для отчёта о транзакциях отправьте `/transactions`.

Уведомления о новых событиях агрегируются ботом и отправляются не чаще одного раза в 5 минут. Если новых транзакций нет, сообщение не отправляется.

## Проверка daemon

Перезапуск Telegram не перезапускает торговый daemon. Его состояние смотрите в `state/status.json`.
Для daemon используйте `STOP_BOT.bat` и `START_MANAGED_BOT.bat`.
