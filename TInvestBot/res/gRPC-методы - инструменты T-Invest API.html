gRPC-методы

С помощью методов сервиса можно получить:

  • информацию об инструментах;
  • расписания торговых сессий;
  • календарь выплат купонов по облигациям;
  • размер гарантийного обеспечения по фьючерсам;
  • дивиденды по ценной бумаге.

Протестировать и отправить запросы можно через REST-методы.
